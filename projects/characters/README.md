# Character worlds

The Founder moved this collection from Sishu Kishore to Project Odisha on 24 October 2026. The published home is https://projectodisha.org/characters/.

The current web pages, artwork, films and reading downloads are in `../site/public/characters/`. The ZIP, PDF and Word downloads are preserved byte-for-byte as assets in this repository’s `characters-archive-2026-10-24` release, keeping the website below its hosting size limit. `release-assets.json` records their original paths and hashes; `source-manifest.json` inventories every original public file.

`source-archive/` preserves the former preparation scripts, editorial data and historical provenance without rewriting source claims. These scripts describe the previous repository/workspace layout and are historical inputs, not the current site build. Do not run them directly against this repository. The normal Project Odisha build publishes the committed web pages. Public navigation and metadata were updated for the new home; narrative text and media were retained.

This move adds no research claims, human review or programme completion credit. Existing draft/proof status and real contributor credits remain in the collection. Production methods are explained in the site’s single editorial-process page.
