SAYING 41 · proverbial saying

Work that does not move forward

ଗୋଦରା କୋଡେ ଯେତେ ମାଡ଼େ ସେତେ

Link to this saying

କାମ କରିଚାଲିଲେ ମଧ୍ୟ ନିଜ କାମ ନିଜେ ନଷ୍ଟ କରୁଥିବାରୁ ଆଗକୁ ବଢ଼ି ନ ପାରିବା।

fruitless-effort

Literal meaning

The swollen-legged person digs; as much as they dig, so much they tread over.

What it means

The image suggests effort whose result is undone as the work proceeds. It can be used for a task that stays unfinished because each advance is cancelled by another action. Its bodily caricature should be recognized rather than turned into a judgment about disabled people.

When you might use it

A document is repeatedly reformatted, and each revision removes changes that the team had already agreed on. (New editorial example, not a collected quotation.)

Cultural context

Godara is rendered as the saying’s description of swollen legs, without diagnosing a medical condition. The interpretation concerns self-defeating work, not physical capacity or personal worth. The figurative explanation is an editorial interpretation, not a separately verified traditional gloss.
